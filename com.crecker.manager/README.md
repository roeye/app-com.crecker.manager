# Crecker Manager

אפליקציית אנדרואיד לניהול מערכות (אתרים, שרתים, תיבות דואר וכו'). לכל מערכת יש מסך משלו עם הפעולות שרלוונטיות רק לה.

במכשיר האפליקציה מופיעה בשם **Spartapp Manager** (`app_name`). שם החבילה: `com.crecker.manager`.

## מערכות קיימות

| מערכת | פעולות | תיעוד |
|---|---|---|
| paisresults.co.il | ביצוע cron data retrieval, בדיקת עדכון אחרון (מתי כל קובץ עודכן בשרת, לפי שעון ישראל, עם התראה על קבצים ישנים) | [docs/systems/paisresults.md](docs/systems/paisresults.md) |
| flightstatus.co.il | ביצוע cron data retrieval (הרצה ידנית של סקריפט ה-cron בשרת, עם זמן ריצה והפלט שלו), בדיקת עדכון אחרון של `flights_data.json` (לפי שעון ישראל, ישן אחרי שעה כברירת מחדל, עם התראה), עם חיבור FTP/SFTP משלו | [docs/systems/flightstatus.md](docs/systems/flightstatus.md) |
| Mail | דואר נכנס מאוחד מכל התיבות (IMAP, **קריאה בלבד**, חסימת תוכן חיצוני ומעקב, שמירת קבצים מצורפים), בדיקת מיילים חדשים (אפשר לתזמן, עם התראה אחת מסכמת) | [docs/systems/mail.md](docs/systems/mail.md) |

לכל מערכת יכולות להיות **הגדרות מערכת** (⚙ במסך המערכת), שמשותפות לכל הפעולות שלה, למשל פרטי החיבור לשרת. לכל פעולה יש גם הגדרות משלה (⚙ במסך הפעולה), כמו תזמון.

## הרצה

- פתיחה ב-Android Studio והרצה רגילה, או משורת הפקודה:
  ```
  gradlew :app:assembleDebug        # בנייה
  gradlew :app:testDebugUnitTest    # בדיקות
  gradlew :app:lintDebug            # lint (שגיאה מכשילה את ה-build)
  ```
- **JDK:** ה-daemon של Gradle רץ על JDK 25 מלא (`gradle/gradle-daemon-jvm.properties`), למשל ה-JBR של Android Studio. אם ה-build נכשל עם `jlink executable … does not exist`, Gradle ממשיך להשתמש ב-daemon שהופעל על JRE (למשל מתוך התוסף של Java ב-VS Code). הפתרון: `gradlew --stop` ואז לבנות שוב.
- **עדכון גרסת Gradle:** בעדכון של `distributionUrl` ב-`gradle-wrapper.properties` צריך לעדכן גם את `distributionSha256Sum`. את הערך לוקחים מהקובץ `…-bin.zip.sha256` ב-services.gradle.org.
- **התקנה על מכשיר משורת הפקודה:** `adb install -r -t app/build/outputs/apk/debug/app-debug.apk`. לא להתקין מ-`app/build/intermediates/`: שם נמצא ה-build של Android Studio, ו-`gradlew` לא מעדכן אותו.
- **בדיקה על המכשיר:** צילומי מסך יוצאים שחורים (`FLAG_SECURE`). את מה שמוצג במסך קוראים עם `adb shell uiautomator dump`.
- minSdk 26, Kotlin + Jetpack Compose (Material 3).

## הגדרות האפליקציה (⚙ במסך הבית)

| קטגוריה | הגדרה | אפשרויות | ברירת מחדל |
|---|---|---|---|
| אבטחה | נעילת אפליקציה | פעילה / כבויה | פעילה |
| אבטחה | נעילה מחדש | מיד / אחרי דקה / אחרי 5 דקות / רק כשהאפליקציה נסגרת | אחרי דקה |
| תצוגה ושפה | מצב תצוגה | לפי המכשיר / בהיר / כהה | לפי המכשיר |
| תצוגה ושפה | שפה | אוטומטי (שפת המכשיר) / English / עברית | אוטומטי |

**נעילת אפליקציה:** כניסה רק עם טביעת אצבע, זיהוי פנים או נעילת המסך של המכשיר (PIN / pattern / סיסמה). אחרי זיהוי פנים תקין נכנסים מיד, בלי ללחוץ "אישור" (אם המכשיר תומך בזה). שינוי הגדרות הנעילה דורש אימות. צילומי מסך חסומים, והתוכן לא מוצג בתצוגת האפליקציות האחרונות.

הממשק קיים באנגלית ובעברית. כיוון התצוגה (RTL/LTR) נקבע לפי השפה. באנדרואיד 13 ומעלה אפשר לשנות את השפה גם מהגדרות המכשיר (שפה לכל אפליקציה).

## התנהגות כללית

- **יציאה:** במסך הבית צריך ללחוץ פעמיים על "חזרה" תוך שנייה. הלחיצה הראשונה מציגה הודעה.
- **שורות סטטוס במסך הבית:** מתחת לכל מערכת מוצגת שורה לכל פעולה, עם נקודה בצבע הסטטוס (ירוק להצלחה, כתום להצלחה חלקית או ביטול, אדום לכשל). ב-Mail מוצגת גם שורה לכל תיבת דואר: מספר החדשים ומספר שלא נקראו, עם נקודה כחולה כשיש חדשים ואדומה כשהחיבור נכשל. אם השורה נשברת, הנקודה בגובה השורה הראשונה.
- **לוג של פעולה:** כל פעולה מציגה לוג חי עם שעה וצבע לכל שורה: ירוק להצלחה, כתום לאזהרה ואדום לשגיאה. בלוג יכולות להופיע גם טבלאות סיכום ובלוק של פלט גולמי, למשל הפלט של סקריפט בשרת. הבלוק מוצג בגופן קבוע ועם גלילה אופקית. הלוג נשמר ב-20 ההרצות האחרונות (☰), ואפשר להעתיק אותו או לשתף אותו.
- **התראות:** יש שני ערוצים. **"כשלים בפעולות מתוזמנות"**: התראה כשהרצה אוטומטית נכשלה או הצליחה רק בחלקה. **"עדכונים מהמערכות"**: התראה על משהו חדש, למשל מיילים חדשים. התראה אחת מסכמת, והיא מחליפה את הקודמת. ההרשאה להתראות מתבקשת כשמפעילים התראה בהגדרות של פעולה.
- **אייקון:** אייקון adaptive וקטורי (אריחי דשבורד על גרדיאנט אינדיגו-סגול), כולל גרסה ל-Themed Icons ואייקון נפרד להתראות. הלוגו מופיע גם בכותרות מסך הבית וההגדרות.
